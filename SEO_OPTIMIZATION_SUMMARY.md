# SEO Optimization Summary for NLMRC Website

## Overview
This document outlines the SEO optimizations implemented for the New Life Mwangaza Rehabilitation Center (NLMRC) website to improve search engine rankings for rehabilitation services and job-related searches in Kenya.

## Key Optimizations Implemented

### 1. **Meta Tags & HTML Head Optimization** (`index.html`)
- **Title Tag**: Optimized with primary keywords "New Life Mwangaza Rehabilitation Center (NLMRC) | Rehabilitation Centers in Nairobi, Kenya"
- **Meta Description**: Comprehensive description including service areas (Nairobi, Machakos, Kajiado, Kiambu)
- **Meta Keywords**: Extensive keyword list covering:
  - Rehabilitation services
  - Volunteer opportunities
  - Teaching jobs
  - NGO positions
  - Location-specific terms

### 2. **Open Graph & Social Media Tags**
- Facebook Open Graph tags for better social sharing
- Twitter Card tags for enhanced Twitter previews
- Proper og:type, og:url, og:title, og:description
- Site name and locale specifications (en_KE for Kenya)

### 3. **Geo-Targeting Tags**
- Geographic meta tags for Kenya/Nairobi
- GPS coordinates for local search optimization
- ICBM tags for location-based services

### 4. **Structured Data (JSON-LD)**
- Schema.org NGO markup
- Organization details including:
  - Name and alternate name (NLMRC)
  - Contact information
  - Service areas (Nairobi, Machakos, Kajiado, Kiambu)
  - Social media profiles
  - Knowledge areas (rehabilitation, youth support, etc.)

### 5. **Sitemap.xml**
- Created comprehensive XML sitemap
- Proper priority settings for pages
- Change frequency specifications
- Covers all major pages including:
  - Home, About, Services
  - Career/Jobs page (high priority)
  - Stories, Gallery, Contact
  - All service sub-pages

### 6. **Robots.txt**
- Configured to allow search engine crawling
- Protects admin areas from indexing
- Sitemap reference included
- Allows all important public pages

### 7. **SEO Component** (`src/components/SEO.tsx`)
- Reusable React component for dynamic SEO
- Updates page title, description, keywords
- Manages Open Graph and Twitter tags
- Handles canonical URLs
- Can be used across all pages

### 8. **Career Page Optimization**
- Dedicated SEO tags for job-related searches
- Keywords targeting:
  - "volunteer jobs in kenya"
  - "paid volunteer jobs in kenya"
  - "teaching jobs kenya"
  - "ngo volunteer jobs in kenya"
  - "rehabilitation center jobs"
  - And 20+ more job-related terms
